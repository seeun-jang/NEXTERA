# 저장소 — 프론트 결정 사항 (백엔드 전달용)

FRONT_ARCHIVE_NOTE.md 5장 "어느 쪽으로 할지 프론트에서 정해 알려 달라"에 대한 답입니다.

## 세션
- **세션 번호를 localStorage로 옮겼습니다.** 키는 그대로 `nx-session`, 형식도 그대로 `S-xxxxxxxx`.
- 예전 sessionStorage 값이 있으면 그 값을 localStorage로 옮겨 씁니다. 이미 쌓인 "내 기록"이 끊기지 않습니다.
- 결과: 같은 브라우저면 새 탭·새로고침·창을 닫았다 열어도 "내 기록"이 이어집니다. 다른 브라우저·시크릿 창은 새 세션입니다.
- `/api/v2`의 모든 호출(시연 흐름 + 저장소 + history)이 같은 세션 번호를 보냅니다.

## 범위
- 저장소 화면의 기본은 **`scope=mine`(내 기록)** 입니다.
- **`scope=all`(모든 접속자)** 은 사용자가 직접 누를 때만 씁니다. 누르면 "다른 사람의 시연도 섞여 있습니다" 안내가 붙고, 번호 칸에 세션 끝 4자리를 함께 보여 줍니다.

## 화면에서 쓰는 것
- 목록: `scope`, `kind`(`overheat`/`deadline`), `result`, `q`, `limit=50`, `offset` — "더 보기"는 `offset = 지금까지 받은 건수`.
- 상세: `archive_id`는 `encodeURIComponent`로 넣습니다.
- 다시 시연: 상세의 `scenario`를 화면의 상황 모양으로 바꿔 기존 시작 흐름(`POST /api/v2/scenario`)을 그대로 탑니다.
- 확률·일치는 `provider === "zoro1"`인 회차에만 표시합니다.
- 결정 영수증의 누적 기록은 지금처럼 `GET /api/v2/history`, `hidden > 0`이면 "저장소에서 N건 더 보기" 버튼.

## 요청 없음
- 삭제 기능은 필요 없습니다.
- 응답 모양 변경 요청도 없습니다.
